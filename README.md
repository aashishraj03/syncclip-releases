# SyncClip

SyncClip keeps your clipboard the same across your devices. Copy text or files on one device and paste them on another.

## Install on Mac

Open Terminal, paste this command, and press Enter:

    curl -fsSL https://raw.githubusercontent.com/aashishraj03/syncclip-releases/main/install.sh | bash

The command downloads SyncClip, installs it in your Applications folder, and opens it. It also takes care of the macOS security warning, so you don't need to allow the app in System Settings.

## Requirements

- A Mac with Apple Silicon (M1 or later). Intel Macs aren't supported yet.
