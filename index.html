SyncClip

Copy on one device. Paste on another.

SyncClip keeps your clipboard the same across your devices, for both text and files.

Download SyncClip for Android

Free APK file for Android phones

How to install

  1. Tap the download button above.

  2. When the download finishes, open the file from your notifications or the Downloads folder.

  3. If Android blocks the install, tap Settings, turn on Allow from this source, go back, and tap Install.

    If Play Protect shows a warning, tap More details, then Install anyway.

  4. Open SyncClip and sign in, or create an account, to link your phone.
